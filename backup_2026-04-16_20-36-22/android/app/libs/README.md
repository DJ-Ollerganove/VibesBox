# libs Ordner

Dieser Ordner enthält lokale AAR-Dateien, die in die App eingebunden werden.

## ShazamKit.aar

Lade die `ShazamKit.aar` Datei herunter und platziere sie in diesem Ordner:

```
android/app/libs/ShazamKit.aar
```

Nach dem Hinzufügen der Datei wird sie automatisch von build.gradle.kts eingebunden.

## Hinweis

Die ShazamKit.aar Datei muss von Apple/Shazam bereitgestellt werden und ist normalerweise nicht öffentlich verfügbar. 
Stelle sicher, dass du die richtige Version für dein Projekt verwendest.
