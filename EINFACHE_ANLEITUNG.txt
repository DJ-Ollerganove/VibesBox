═══════════════════════════════════════════════════════════════
  EINFACHE ANLEITUNG: PWA auf Firebase Hosting deployen
═══════════════════════════════════════════════════════════════

SCHRITT 1: ÖFFNE EIN NEUES TERMINAL
────────────────────────────────────
- Schließe das aktuelle Terminal/PowerShell-Fenster
- Öffne ein NEUES PowerShell oder CMD-Fenster
  (Rechtsklick auf Start-Menü → Windows PowerShell oder Eingabeaufforderung)


SCHRITT 2: NAVIGIERE ZUM PROJEKT
─────────────────────────────────
Tippe ein und drücke Enter:
  cd C:\Users\Ollerganove\Desktop\dj-og-app


SCHRITT 3: PRÜFE OB FIREBASE FUNKTIONIERT
──────────────────────────────────────────
Tippe ein und drücke Enter:
  firebase --version

Falls eine Fehlermeldung kommt:
  → Gehe zu SCHRITT 4
Falls eine Versionsnummer angezeigt wird:
  → Gehe zu SCHRITT 5


SCHRITT 4: FIREBASE INSTALLIEREN (nur wenn nötig)
──────────────────────────────────────────────────
Tippe ein und drücke Enter:
  npm install -g firebase-tools

Warte bis die Installation fertig ist.


SCHRITT 5: BEI FIREBASE ANMELDEN
─────────────────────────────────
Tippe ein und drücke Enter:
  firebase login

- Ein Browser-Fenster öffnet sich automatisch
- Melde dich mit deinem Google-Konto an
- Erlaube Firebase den Zugriff
- Das Terminal zeigt "Success! Logged in as ..."


SCHRITT 6: PROJEKT VERBINDEN (nur beim ersten Mal)
──────────────────────────────────────────────────
Tippe ein und drücke Enter:
  firebase use dj-ollerganove

Falls das nicht funktioniert, versuche:
  firebase init hosting
  → Wähle: "Use an existing project"
  → Wähle: "dj-ollerganove"
  → Public directory: "public"
  → Single-page app: "Yes"


SCHRITT 7: PWA DEPLOYEN
─────────────────────────
Tippe ein und drücke Enter:
  firebase deploy --only hosting

Warte bis der Upload fertig ist (kann 1-2 Minuten dauern).


SCHRITT 8: FERTIG!
──────────────────
Am Ende siehst du eine Meldung wie:
  "Hosting URL: https://dj-ollerganove.web.app"

Das ist deine Website! Öffne diese URL im Browser.


═══════════════════════════════════════════════════════════════
  ALTERNATIVE: ÜBER FIREBASE CONSOLE (OHNE TERMINAL)
═══════════════════════════════════════════════════════════════

Falls das Terminal nicht funktioniert:

1. Öffne im Browser: https://console.firebase.google.com/

2. Klicke auf dein Projekt: "dj-ollerganove"

3. Im linken Menü klicke auf "Hosting"

4. Klicke auf "Get started" (oder "Add another site")

5. Folge den Anweisungen:
   - Installiere Firebase CLI (falls nötig)
   - Oder verwende "Drag & Drop" um die Dateien hochzuladen

6. Lade alle Dateien aus dem Ordner "public" hoch:
   - index.html
   - styles.css
   - manifest.json
   - service-worker.js
   - icon-192.png
   - icon-512.png

  HILFE BEI PROBLEMEN
═══════════════════════════════════════════════════════════════

Problem: "firebase: command not found"
Lösung: Öffne ein NEUES Terminal-Fenster und versuche es nochmal

Problem: "npm: command not found"
Lösung: Installiere Node.js von https://nodejs.org/

Problem: "Permission denied"
Lösung: Führe PowerShell als Administrator aus (Rechtsklick → Als Administrator ausführen)

Problem: "Project not found"
Lösung: Verwende "firebase init hosting" und wähle dein Projekt aus
